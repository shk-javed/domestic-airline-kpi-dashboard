# ✈️ Domestic Airline KPI Dashboard  
### Power BI + DAX + Data Modeling

## 📌 Project Overview  
This project showcases an interactive airline analytics dashboard built using Power BI.  
It analyzes a dataset of 9,651 domestic flights across 12 airlines to extract meaningful business insights.

---

## 📊 Key Features  

- Total Flights KPI  
- Average Ticket Price by Airline  
- Peak Departure Hour Analysis  
- Flight Duration Buckets  
- Top 3 Cheapest Routes  
- Top 3 Most Expensive Routes  
- Flights by Source Distribution  

---

## 🛠️ Tools Used  

- Power BI  
- DAX (Data Analysis Expressions)  
- Data Modeling  
- Power Query  

---

## 📂 Dataset  

- Custom dataset (self-created)  
- 9,651 flight records  
- 12 airlines  
- No external data used
